A deterministic, pure-Python program (standard library only, no network) that draws a 1024x1024 newspaper front page summing up Wednesday 18 November 2026's world news in one image: the U.S. strike on a Revolutionary Guard missile site on Qeshm Island as the lead story, plus Ukraine's second strike on the Kerch Bridge, the Shenzhen summit of Xi, Putin and Trump, Category 5 Cyclone Xavier in the Cook Islands, the doubling Ebola outbreak in DR Congo, and Mary Peltola's Alaska Senate win in the bottom ticker. Every letter is rendered from a hand-defined 5x7 bitmap font, so the text is always perfectly formed, and two runs produce byte-identical output. Run it with `python3 main.py`; it writes the poster to /output/entry.png (falling back to ./entry.png).

## Run it

```sh
python3 main.py
```
